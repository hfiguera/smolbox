# SmolBox 0.6.1

SmolBox 0.6.1 defaults to **SmolVM 1.35.1**, adds explicit terminal arguments,
and introduces an opt-in single-node Kubernetes development preview.

## Changes

- Support the unmodified 1.35.1 SDK, including bounded padded telemetry reads,
  legacy macOS rootfs identity and branch-proof compatibility. Explicit older
  runtime versions and approvals remain supported.
- Add terminal arguments for HTTP 1.35.1 and negotiated Embedded Port packages.
  Launch generated scripts through an image interpreter, for example
  `program: "/bin/sh", args: ["/workspace/generated.sh"]`.
- Add disposable OCI execution, binary commands/files, artifact collection,
  cancellation and durable controller recovery through the Kubernetes preview.
  It requires one explicitly enrolled Linux/K3s node and the fixed offline policy.
  Production/multi-node operation and broader backend parity remain future work.
- Bound held-branch credential resolution by the release deadline.
- Fix Kubernetes queued admission, ready cancellation/recovery, output transport
  budgets and lease renewal while recovery collection runs.

## Upgrade

Hex remains unpublished during final qualification. Use the matching source:

```elixir
{:smolbox, github: "hfiguera/smolbox", tag: "v0.6.1"}
```

Install the separately published native bundle with
`mix smolbox.embedded.install --tag v0.6.1`. The library does not update installed
helpers or migrate retained SDK domains. Pin existing workers/checkpoints to
their installed/captured runtime, drain work and enroll a separately approved
1.35.1 deployment while preserving the original paths and unknown work.

Upgrade all shared readers, writers and custom stores before using terminal
arguments (codec v55, `terminal_arguments: 1`). Program-only terminal records
retain their earlier encodings and fingerprints.

Before enabling Kubernetes, coordinate shared readers/writers for selective
codec v54 and apply the supplied PostgreSQL example migration
`20261113000000_kubernetes_bindings`. Custom stores need the atomic
`kubernetes_backend: 1`, `backend_bindings: 1` and `backend_recovery: 1` contracts.
Follow the preview guide for node authority and setup; keep historical proof
versions unchanged.

## Qualification

The implementation completed scoped local qualification. Stable `v0.6.1`
archives were built and attested on GitHub-hosted Apple Silicon, Linux x86_64
and Linux ARM64 runners. All six current/minimum public installer lanes passed
in fresh standard accounts with Rust absent, using both automatic version
selection and explicit tag selection. Public provenance, guest output `42`,
zero SDK rows/reservations, unchanged installed assets and owned cleanup verified.
macOS kept Gatekeeper enabled and verified signatures plus the hypervisor entitlement.
All temporary accounts, HOME directories and account locks were removed, and both
Linux guests were stopped.
