## Upgrade requirements

The chosen version is 0.1.3, but the record format change requires coordinated
controller deployment. Every codec write uses v2, including offline work. New
readers accept exact legacy v1 records; 0.1.2 readers reject v2. After v2 writes,
there is no built-in downgrade. The default worker changes to 1.16.0, with explicit
1.14.1 and 1.14.6 retained for offline configurations. Network policies require
1.16.0. See [the upgrade procedure](../recovery.md#upgrading-to-0-1-3).
