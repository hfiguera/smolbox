# SmolBox 0.4.2

SmolBox 0.4.2 makes the first execution setup complete and improves diagnostics
when a worker inventory contains an unsupported machine network policy. The
default worker remains **smolvm 1.22.0**.

## Changes

- Return the redacted `:unsupported_network_policy` category for unsupported
  networking. Machine list failures retain operation `:list` and report
  `:dispatch_uncertain` after the GET request. Inventory validation remains strict.
- Include image preparation, separate Linux worker state and ports, an empty
  inventory check, and networking restrictions in Getting Started. Clarify the
  separate macOS account or host requirement and reduce repeated introductory text.
- Ship a downloadable Livebook in HexDocs and the package. It checks Python's
  exit code, collected `42` output, duplicate submission identity and VM cleanup.

## Upgrade note

Upgrade every controller and reader sharing a durable store before allowing
records containing `:unsupported_network_policy`. Older readers reject this
new category. There is no SQL migration, codec revision or worker default change
from 0.4.1. Custom error handlers must also accept the new category.

Read [Upgrading to 0.4.2](https://hexdocs.pm/smolbox/0.4.2/upgrading-to-0.4.2.html)
for deployment order and rollback considerations.
