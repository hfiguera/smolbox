## Upgrade requirements

Despite its patch version number, 0.1.3 requires coordinated upgrades of
controllers sharing records encoded by `SmolBox.Store.Codec`. Every new write
uses v2, including offline executions. New readers accept legacy v1 records;
0.1.2 readers reject v2. There is no built-in downgrade after v2 writes.

The default worker changes to smolvm 1.16.0. Older offline workers remain usable
with explicit 1.14.1 or 1.14.6 configuration. Network policies require 1.16.0.
The [upgrade procedure](../recovery.md#upgrading-to-0-1-3) explains deployment,
state preservation and rollback limits. These requirements appear in the README,
changelog, ExDoc and GitHub release notes.
