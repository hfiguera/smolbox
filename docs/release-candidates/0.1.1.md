this documentation and validation release, including Hex, HexDocs and GitHub
publication. New execution was restricted to Linux.

## Validation scope and results

The maintainer's Linux-only instruction supersedes the original two-host release
matrix for this patch. All new execution took place on `ssh linux` and hosted
Linux CI. The earlier macOS results remain historical evidence for the unchanged
library; no new 0.1.1 macOS run or macOS resource qualification is claimed.

[Ordinary CI](https://github.com/hfiguera/smolbox/actions/runs/34191771307) passed
all **18 jobs** at the exact release commit, without skipped, cancelled or failed
jobs. Clean, separate checkouts on `ssh linux` also passed these lanes:

Each deterministic run executed four doctests, six properties and 184 ordinary
tests. The fourteen live cases excluded from those commands ran separately.
ExUnit's different summary formats were normalized; exclusions are not passes.

The canonical Elixir 1.20.4/OTP 29.0.6 checkout passed formatting, unused-lock
checks, forced compilation with warnings as errors, zero static dependency
cycles, Dialyzer, Credo, ex_slop, ex_dna and Credence. All eight failing/passing
canary pairs executed successfully. Production-library coverage was **95.40%**
against the 90% floor. Both host examples passed compilation, forced Dialyzer
and dependency audits; the durable example also had zero dependency cycles.

The durable example retains the narrowly scoped, version-guarded Decimal advisory
exception documented in the [CI guide](../../scripts/ci/README.md#temporary-decimal-advisory-exception).
Other advisory checks remain enabled, and dependency-audit refreshes succeeded.

Live tests used pinned SmolVM 1.14.1 and verified native Python/Node artifacts.
Preflight checked worker ownership, executable/artifact digests, KVM access,
private database settings and empty inventories. Every recorded step checked the
candidate identity and clean source state before and after execution.

The task-owned PostgreSQL 16.15 instance used a private Unix socket, no TCP
listener and thirty connections. Final checks found zero reserved slots, zero
records needing work and no noninternal test triggers before stopping it. The
stopped-database probe then failed closed. Worker inventories were empty and
fault-service ports were free. The original worker and shared database remained
running; private test data was retained.

## Package, documentation and publication

Current and minimum production consumers on Linux used the **same saved archive**.
Both compiled with warnings as errors and exercised the public client and explicit
supervision, with only runtime dependencies. Every packaged file matched the
release Git object. Examples, tests, analyzers, scripts, external references and
release attestations were absent from the package.

ExDoc passed warnings as errors and local file/fragment checks across **42 pages**.
All **168 generated source links** addressed valid files and lines at `v0.1.1`;
the additional versioned guide/example destinations were checked as well. Version,
changelog, repository ownership/metadata, normalized SPDX MIT text and runtime
dependency license declarations were reviewed.

An initial publishing dry run waited for Hex authentication and was terminated.
Its zero process exit was explicitly rejected as evidence of success. After
authentication, the complete `mix hex.publish --dry-run --yes` reached both the
package and documentation checks. Rebuilding the archive produced identical bytes.
The temporary evidence checker was also adjusted to recognize the older ExUnit
summary formats; no package or test-source correction was necessary.

After acceptance, `main` was advanced to the tested commit and the annotated tag
was pushed and verified. Hex publication ran from the clean Linux checkout with
the maintainer's authenticator verification. The downloaded public archive was
byte-for-byte identical to the validated archive and matched Hex's checksum.
Six public HexDocs pages returned the expected version, content and source links.

A separate consumer with an empty Hex cache fetched the documented
`{:smolbox, "~> 0.1.1"}` dependency from Hex, compiled it, exercised the client
and supervisor, and matched all 86 packaged file hashes. The GitHub Release was
created afterward, with the validated archive attached.
