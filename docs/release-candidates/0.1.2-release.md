## Relationship to live validation

PR #5 was squash merged as `644cc645d5d4d4b7fc84191b138a9581538d9b20`, with
its tree identical to the accepted branch head. Release finalization changes
three packaged documents: the changelog, compatibility guide and host integration
guide. It removes their unpublished status text. The implementation plan and CI
README also receive repository-only status updates.

Library code, tests, tooling implementations, example code, dependency locks and
worker configuration match the live-tested candidate
`2a85abfd07afeb7bb2bbd07fab2056271ebf7040`. Those live results retain their original
commit identity: nine runtime cases on native macOS, fourteen in the disposable
Linux lab, sixteen PostgreSQL store cases and twenty-five durable recovery cases
on each host, plus four explicit legacy managed cases on each. The earlier
artifact, service-failure and exhaustion campaigns retain their recorded scope.

This publication did not rerun live or exhaustion tests for documentation changes.
File comparison establishes the relationship to the tested executable tree; it is
not reported as execution of those suites at the release commit.

## Final release checks

[GitHub CI run 34561415767](https://github.com/hfiguera/smolbox/actions/runs/34561415767)
passed all 18 jobs at the release commit, including compatibility lanes,
durable-store checks, analyzers, audits, coverage, docs and package consumers.

Fresh local checks passed on Linux and native macOS with Elixir 1.20.4/OTP 29.0.6:

- Complete `mix ci`, all eight bad/clean analyzer canary pairs and 95.41% coverage.
- 200 deterministic cases and 23 standalone tooling cases per host. The fourteen
  excluded live cases are not counted as passes in these runs.
- ExDoc builds and checks of local links across 42 pages.
- Six fresh consumers of the same final archive: current and minimum dependencies
  on the canonical pair, and minimum dependencies on Elixir 1.18.4/OTP 27.3.4.15,
  on each host. All assert the default 1.14.6 configuration and explicit 1.14.1.
- All 89 package files match the release commit. Metadata, license and 168 source
  file/line links were verified. The authenticated publishing dry run passed.

## Public verification

After publication, the downloaded Hex archive matched the final archive exactly.
Fresh registry consumers on Linux and macOS resolved `smolbox == 0.1.2`, compiled
and exercised client/supervisor construction and both runtime configurations.
Their lock checksums and all 89 installed files matched the published archive.
These are package installation tests with a synthetic client transport; they are
not additional real-worker tests.

The first Linux registry consumer attempt stopped before Mix could start because
its temporary directory did not inherit the repository toolchain selection.
The helper now selects Elixir 1.20.4/OTP 29.0.6 explicitly; fresh consumers then
passed on both hosts. This required no library or package change.

Six public documentation pages report version 0.1.2, all three new SmolVM evidence
assets match the repository bytes, and the tagged worker configuration source is
available and matches the release. The GitHub release is public and its attached
archive has the same SHA-256 as Hex.

Qualification remains `:development`. Linux ARM64 with SmolVM 1.14.6 remains
unqualified, and no general hostile-code isolation or hard macOS host limits are
claimed. Publication checks did not restart existing workers, databases or the
Linux lab. The prior verified live-fixture cleanup remains undisturbed.

This report and its JSON are excluded from the Hex archive. Their later commit
does not replace or move the release tag.
