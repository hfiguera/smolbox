# SmolBox 0.1.4 release validation

Historical checkpoint: superseded by the [verified publication](0.1.4-release.md).

Status at preparation: metadata and documentation complete; final release checks
and publication were pending.

Base: `8ccd1111301142d7eeb6599323ecc0fde8e87547` (merged smolvm 1.16.1 qualification).
Branch: `release-0.1.4`.

This release defaults to smolvm 1.16.1 and separates managed disposal from graceful
preservation. Explicit 1.16.0, 1.14.6 and 1.14.1 workers remain supported; controlled
networking requires 1.16.0 or 1.16.1. Follow [Upgrading to 0.1.4](../recovery.md#upgrading-to-0-1-4).
No additional public API or record schema migration is introduced.

The release preparation changes version metadata and documentation only. The
[1.16.1 qualification report](../runtime-1.16.1-qualification.md) and recorded
[cleanup](../evidence/cleanup-preservation-disposal.json),
[admission](../evidence/smolvm-1.16.1-admission.json) and
[default selection](../evidence/smolvm-1.16.1-default.json) evidence retain their
original source revisions. Their live runs are not new runs against release
metadata. Final validation must compare executable source to the merged baseline
and validate the exact release commit and archive.

Graceful stop can fail when guest filesystem synchronization fails. Unknown
work may remain retained for operator intervention; successful disposal is not
a guarantee that graceful preservation succeeds under exhaustion. No macOS
exhaustion or adversarial tests, macOS IPv6 qualification, Linux ARM64 support or
new host resource guarantee is claimed.

The final publication report will record the release commit, archive, CI,
consumer checks, source-link verification, Hex publication and public docs checks.
No existing release or historical evidence is rewritten.
