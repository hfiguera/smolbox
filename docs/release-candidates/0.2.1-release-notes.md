# SmolBox 0.2.1

SmolBox 0.2.1 adds qualified smolvm 1.19.0 support, clarifies the managed-machine
store contract, and improves the examples, documentation and test suite.

## Upgrade note

**The default worker version is now smolvm 1.19.0.** If your worker still runs
1.17.0, explicitly configure `runtime_version: "1.17.0"` before upgrading SmolBox,
or upgrade the worker separately. Keep checkpoint approvals pinned to their
capture version too. Updating the library does not install smolvm.

No SmolBox store schema, codec or SQL migration is introduced when upgrading
from 0.2.0. Applications upgrading from 0.1.x must still follow the coordinated
0.2.0 upgrade procedure.

Read [Upgrading to 0.2.1](https://hexdocs.pm/smolbox/0.2.1/upgrading-to-0.2.1.html).
During 0.x development, patch releases may update the qualified worker default;
explicit version configuration lets applications retain a supported worker.

## Changes

- Qualify smolvm 1.19.0 on Linux x86_64 and macOS Apple Silicon across execution,
  persistence, recovery, checkpoints, networking and worker fault scenarios.
- Specify managed-machine storage operations with explicit argument and result
  types and documented transaction/recovery semantics. Existing adapters keep
  the same callbacks and stored formats.
- Move specification classification into the shared domain layer and encapsulate
  terminal session lookup within the runtime, preserving public behavior.
- Add a Phoenix LiveView community workspace example in the repository. It keeps
  its 0.2.0 package lock and explicit 1.17.0 worker pin.
- Improve contract test concurrency, fix test synchronization races, update
  ex_slop to 0.4.5, and clarify lifecycle and deployment documentation.

## Validation and limits

The worker qualification includes real Linux and macOS results. It remains
`:development` qualification; in-place upgrades of retained worker disks,
rollback of modified upstream state and cross-version checkpoint portability
are not established. No new pause/resume, registry provisioning, automatic
workload restart or process supervision API is added.

See the [qualification report](https://hexdocs.pm/smolbox/0.2.1/runtime-1.19.0-qualification.html)
for evidence and limits, including the retained receipts and missing detailed
logs from the first Linux execution/recovery phases. Final release publication
and its exact-commit CI must be recorded separately from local preparation.
