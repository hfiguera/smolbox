Historical preparation status: prepared and validated locally before publication.
Version 0.1.5 is now published; see the [verified publication record](0.1.5-release.md).

Base: `a3781deb69cb955cb5d981e5b766e6957e23af17` (merged checkpoint execution).
Branch: `prepare-0.1.5`.

## Release scope

Version 0.1.5 adds operator-approved idle, offline checkpoint execution using the
existing HTTP client and managed lifecycle. It includes examples for ephemeral
and PostgreSQL-backed runtimes, recorded recovery checks, preparation scripts and
performance measurements. smolvm 1.16.1 remains the default and is required for
checkpoints. Image execution retains explicit older supported worker versions.

Checkpoint records use schema v3. **Upgrade every controller sharing a store
before submitting checkpoint work.** Image executions keep v2 and their existing
fingerprints. There is no new SQL migration, but completed checkpoint records
remain unreadable to older controllers; disabling new submissions alone does not
permit rollback. Follow [Upgrading to 0.1.5](../recovery.md#upgrading-to-0-1-5).

## Validation boundaries

This preparation changes version metadata and documentation only. Library,
test, developer-tool and executable example sources must match the merged base;
`mix.exs` changes only the version. Earlier qualification retains its actual
revisions and is not relabeled as new release validation:

- [Native checkpoint checks](../evidence/checkpoint-executions.json): ordinary
  execution on Linux x86_64 and macOS Apple Silicon, deterministic tests,
  schema-v3 persistence and package consumers.
- [Durable example](../evidence/checkpoint-durable-example.json): three focused
  Linux cases across independent application processes, with no command replay
  and verified cleanup/capacity release.
- [Cache and preparation measurements](../evidence/checkpoint-cache-benchmark.json):
  284 executions including warmups in the disposable Linux lab, kept separate
  from native performance claims.

These do not add networked checkpoints, arbitrary resumed workloads, capture,
live branching or pools. The full checkpoint failure matrix, macOS durable
checkpoint recovery, macOS IPv6 enforcement and Linux ARM64 remain outside the
recorded evidence. There is no new production isolation or hard host quota claim.
