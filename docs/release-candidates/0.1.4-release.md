## Upgrade requirements

The default worker changes from smolvm 1.16.0 to **1.16.1**. Upgrade the separately
installed worker using the drain and verification procedure, or explicitly set
`runtime_version: "1.16.0"` before updating the library to retain that worker.
Explicit 1.14.6 and 1.14.1 offline workers remain supported. Controlled networking
requires 1.16.0 or 1.16.1; offline remains the default. There is no automatic fallback.

There is no additional public API or record schema migration from 0.1.3.
Applications coming from 0.1.2 or earlier still need the coordinated v2 record
upgrade. The [upgrade procedure](../recovery.md#upgrading-to-0-1-4) also explains
the distinction between completed-work disposal and unknown-outcome preservation.
Failed graceful stops can retain unknown work for operator resolution, and
upgrading never resets exhausted cleanup budgets or replays uncertain commands.
