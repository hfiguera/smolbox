# SmolBox 0.3.1

SmolBox 0.3.1 qualifies smolvm **1.20.2** and makes it the default on Linux
x86_64 and macOS Apple Silicon. It updates security dependencies and improves
checkpoint path compatibility and export metadata, retaining the registry,
export, checkpoint and branch APIs introduced in 0.3.0.

## Upgrade note

**If your worker still runs 1.19.0, explicitly set `runtime_version: "1.19.0"`
before upgrading SmolBox, or upgrade the worker separately.** Keep checkpoint
approvals pinned to their capture runtime. Updating the package does not install
smolvm or convert existing checkpoints.

There is no SQL migration, new store capability or codec revision from 0.3.0.
However, older readers can reject receipts containing the new runtime version.
Upgrade shared controllers and readers before writing those records; reverting
application code alone is not a complete rollback.

Read [Upgrading to 0.3.1](https://hexdocs.pm/smolbox/0.3.1/upgrading-to-0.3.1.html)
for the deployment sequence and earlier-release migration requirements.

## Changes

- Qualify official smolvm 1.20.2 across execution, persistent machines, durable
  recovery, terminals, files, networking, checkpoints and branches. Retain
  explicitly selected older supported runtimes.
- Accept `.checkpoint` alongside `.smolcheckpoint`. Existing managed capture
  filenames remain unchanged, and filename changes do not convert artifacts.
- Record the actual worker runtime in managed export results.
- Require Mint 1.11 or later and update example dependency locks for security
  fixes, including the community workspace's test-only `lazy_html` dependency.
- Add a separate community workspace saved state walkthrough, with branch
  comparisons and explicit checkpoint file cleanup. Its published 0.3.0 lock
  remains intact for tutorial readers.
- Add a practical exports/checkpoints/branches comparison guide and a separate
  1.20.2 physical Linux benchmark repetition. Historical figures stay unchanged.

## Evidence and limits

The [runtime qualification report](https://hexdocs.pm/smolbox/0.3.1/runtime-1.20.2-qualification.html)
records the preceding Linux and native macOS campaign, including platform-specific
coverage. The physical Linux comparison completed 439 stages and verified empty
machine inventory and zero remaining reservations. It describes one workload
with warm caches, not a universal performance ranking or a randomized comparison
between runtime versions.

Qualification remains `:development`. Cross-version checkpoint restore,
in-place upgrades of retained worker state and rollback of the upstream database
are not established. Terminal disconnect behavior changed in the tested process
tree, but absent exit evidence still means an unknown outcome, never automatic
replay or guaranteed cancellation. No resize, migration or concurrent managed
command API is added.

These are draft release notes. Final exact-commit CI and bounded real-worker
checks, tag creation, Hex publication and documentation availability must be
confirmed separately from preparation. The preceding qualification is evidence
for the runtime change, not a claim that the final release commit was tested live.
